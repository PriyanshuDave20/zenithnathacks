# Frontend lane (src/components)
Frontend only. Do not edit `src/app/api`, `src/lib/server`, or `src/components/input` (owned by Backend 2; render options as large targets and listen for `SelectEvent` from `src/lib/contracts/input.ts`). Build against `src/lib/mocks` until the real route lands.
Mobile-first (~390px), large tap targets, high contrast. No patient data in storage; session state is memory only.
See `docs/TEAM.md` and `docs/HANDOFF.md`.
